Kritik & saran.

Menemukan bug, punya masukan, atau mau request fitur? Kirim lewat form ini — pesannya akan dibuka lewat aplikasi email kamu ke Gmail kami.

Apakah semua web di galeri ini gratis?

Ya, keempat web gratis dipakai. Tidak ada biaya langganan dan tidak ada fitur yang dikunci di balik pembayaran.

Apakah perlu instal aplikasi?

Tidak. Semua web jalan langsung di browser HP maupun PC — buka linknya, langsung pakai.

Apakah data & API key saya aman?

API key (mis. Groq, Gemini, YouTube) hanya tersimpan di browser kamu masing-masing dan tidak pernah dikirim ke server kami. Kami tidak menyimpan file atau data pribadi kamu.

Web mana yang paling cocok untuk saya?

Terjemah game visual novel → VNTranslate. Unduh video/audio → Downloader Pribadi. Bikin klip vertikal → Auto Clipper. Riset channel YouTube → Channel SEO.

Tombol kirim akan membuka aplikasi email kamu dengan pesan yang sudah terisi, ditujukan ke Gmail kami. Tidak ada data yang tersimpan di web ini.
